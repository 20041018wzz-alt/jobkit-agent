# 求职工作台（示例知识库 · Sample Job Search）

## [JOB-01] 材料目录

- 全部求职材料统一放 `jl` 目录：8 个方向的简历版本（md 真源 + docx 投递 + pdf 预览），命名规则 `简历-<方向>-<姓名>.<ext>`
- 方向清单：AIAgent、服务端研发、后端Agent、平台开发、全栈开发、前端开发、软件测试、IT运维技术支持
- 配套材料：项目讲解与面试题库、AI-Agent 面试题集（网络整理）、学习路线、学籍在线验证报告
- 其他：照片文件、旧版简历

## [JOB-02] 生成脚本

- 位于工作区根目录的 python-docx 脚本：生成中文简历 docx（微软雅黑、页边距收紧、一页布局、姓名下分割线、右上角照片位）
- 脚本分工：AI Agent 版、多方向批量版、研发/服务端版、IT 运维技术支持版
- 流程：先改 md（唯一真源）→ 同步 docx/pdf → 确认仍是一页 → 把路径回给本人

## [JOB-03] 简历写作规范（硬性要求）

1. 一页：不多不少，内容占满一页；删项目时优先删最弱的，不压缩字号
2. STAR 法则：背景/任务 → 动作（技术）→ 结果（量化），每项目 2–3 条
3. 量化密集：4 秒 → 2 秒内、Recall@4 = 100%、34/44 个 pytest、11–12 模块、11 张表
4. 结构：姓名 → 求职意向 + 2–3 行能力概括 → 教育背景 → 专业技能（分类加粗 + 熟练度标签）→ 项目经历 → 教学实践/其他 → 自我评价（固定三条）
5. 按岗位定制：重排项目顺序、重写定位句、把 JD 关键词提前
6. 输出三件套：md + docx + pdf
7. 不写没有的内容：凡是没有记录的经历一律不写（缺失项只维护在「待补齐项」条目里）

## [JOB-04] 面试准备材料

- 已具备：项目逐句讲解、30 秒/3 分钟话术、防追问三金句、知识点总表、场景设计题（两项目融合、新 Agent 任务五步法、500 QPS 改造、如何证明 RAG 靠谱）、数字口径表、自检清单、网络题集
- 高频考点：LangGraph 状态图与条件路由、多智能体三模式（路由式/Supervisor/Handoff）、ReAct / Plan-and-Execute / Reflexion、Function Calling 原理与失败处理、RAG vs 微调、切分粒度 = 检索粒度、top-k vs 阈值、引用溯源两道闸、MockLLM 不断言文本、SSE vs WebSocket、指数退避、Docker 非 root/HEALTHCHECK/数据卷、golden set 指标
- 讲解写法：三段式逐句讲解 + 白话 + 小标题，避免堆术语

## [JOB-05] 学习路线（约 6 个月 / 150 小时）

1. 第 1–2 周：项目 3 分钟口述、Linux/systemd、minikube 部署 RAG
2. 第 2–3 月：PyTorch（李沐 d2l 前 10 章）+ 传统任务闭环 + LoRA/PEFT 微调
3. 第 4–5 月：vLLM/Ollama、GPTQ/AWQ/INT8 量化、流式与 batch 对比、Prometheus
4. 第 5–6 月：行业场景 demo（手册 RAG、工单意图分类、评论情感分析）+ 八股

自评缺口：PyTorch / 微调、推理加速与量化、K8s。

## [JOB-06] 待补齐项

- 求职参数类：期望薪资、出差意愿、可实习时间
